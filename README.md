# HW Lissajous curve

1st year "FPGA design" course's group project to implement Lissajous's curve generator on FPGA platform on VHDL.

The project consists of 4 parts:

- Lissajous curve generator - Dmitriy Salov
- 2 ADC inputs to curve generator - Dmitrii Malyga
- 2 in-system sinus generators for debug - Ilya Timofeev
- VGA controller to output curve on display - Daniil Kozyrev
